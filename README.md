# Experiência como Aluno iniciante - Documentação

Este repositório foi criado para documentar minha experiência de aprendizado utilizando o GitHub, versionamento de código e ferramentas colaborativas no desenvolvimento de projetos.

## Objetivo

Registrar os principais conhecimentos adquiridos, desafios enfrentados e recursos utilizados durante o processo de desenvolvimento do projeto prático.

## Sobre o Projeto

Este projeto tem como objetivo explorar o uso de versionamento de código, colaboração em equipe e boas práticas de documentação por meio do GitHub. A ideia é simular um ambiente real de desenvolvimento, utilizando ferramentas e processos amplamente utilizados no mercado.

## Aprendizados

- Criação e gerenciamento de repositórios públicos e privados.
- Edição e atualização de arquivos via interface web e Git local.
- Uso de branches para organização de tarefas.
- Escrita de documentação clara no README.md.
- Criação e acompanhamento de issues e pull requests.

## Dificuldades Encontradas

- Configuração inicial do Git e do repositório remoto.
- Resolução de conflitos em merges.
- Compreensão do fluxo de trabalho colaborativo (fork, clone, pull request).
- Adaptação à escrita de documentação detalhada.

## Soluções Adotadas

- Consulta à documentação oficial do GitHub ([docs.github.com](https://docs.github.com/)).
- Visualização de vídeos e tutoriais práticos.
- Prática contínua dos comandos e fluxos.
- Troca de experiências com colegas e professores.

## Recursos Utilizados

- GitHub
- Visual Studio Code
- Terminal (Bash/Prompt de Comando)
- Tutoriais e artigos online
